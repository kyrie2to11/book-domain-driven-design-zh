## 本地开发 & 阅读

使用 Node.js 24 和 Yarn 1，在仓库目录运行：

```sh
yarn install --frozen-lockfile
yarn docs:dev
```

本地访问 http://localhost:8080/ 。推送到 `master` 后，GitHub Actions 会构建并发布在线阅读站。
